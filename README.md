# LootBox

A private, ad-free Android downloader starter project.

## Current features
- Dark purple/cyan interface
- Direct HTTP/HTTPS file downloads using Android DownloadManager
- Background download handling and completion notifications through Android
- Files saved to the device Downloads folder
- No ads and no account required

## Build
GitHub Actions builds a debug APK on every push to `main`, and can also be started manually from the Actions tab. Download the `LootBox-debug-apk` artifact from a successful run.

## Responsible use
Use direct links only for files you own or are authorized to download. LootBox does not bypass DRM, paywalls, login controls, platform advertisements, or service restrictions.

Package: `com.lootbox.downloader`
